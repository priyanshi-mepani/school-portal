# School Portal System

A web-based School Portal developed as part of my BTEC IT coursework.

## Overview

The project demonstrates how PHP, HTML, CSS, and SQL can be used to build a basic school management portal.

## Features

- Student registration and login
- Student dashboard
- Course enrolment
- Database integration
- Basic user management

## Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** SQL / MySQL

## Setup

1. Install a local PHP development environment, such as XAMPP.
2. Place the project folder in the local web server's document directory.
3. Create a MySQL database for the project.
4. Import the cleaned sample database SQL file.
5. Update the database connection settings in `db.php` with your local settings.
6. Open the project through your local server in a web browser.

## Learning Outcomes

This project helped me practise PHP development, database integration, user registration, login workflows, and building web application pages.

## Note

This project was created for educational purposes as part of my BTEC IT coursework. It is a learning project and should be reviewed and tested before being used in a real school environment.
